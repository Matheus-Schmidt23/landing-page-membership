# Landing Page — Membership PM3

Landing page estática para o Membership da PM3.

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — estilos
- `assets/js/main.js` — carrosséis, FAQ accordion, menu mobile
- `assets/img/` — imagens usadas na página

## Rodar localmente

Como é uma página estática, basta abrir o `index.html` direto no navegador. Se preferir rodar via servidor local (Windows, sem Node/Python):

```bash
powershell -ExecutionPolicy Bypass -File "serve.ps1"
```

Depois acesse `http://localhost:8080`.
